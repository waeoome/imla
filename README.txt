درب الإملاء — إعداد وتصميم: وائل الخزاعي

طريقة النشر على GitHub Pages:
1) ارفع كل الملفات في هذا المجلد إلى المستودع كما هي (index.html وmanifest.webmanifest وsw.js والأيقونات وLICENSE.txt).
2) من Settings ← Pages اختر Deploy from a branch ثم main و/(root).
3) افتح الرابط https://اسم-المستخدم.github.io/اسم-المستودع/ ؛ على الهاتف اختر «إضافة إلى الشاشة الرئيسية» ليعمل كتطبيق، ويعمل بعد أول زيارة بلا إنترنت (عدا الخطوط التي تُخزَّن بعد أول تحميل).

4) للهاتف: افتح الرابط في Chrome ثم القائمة ⋮ ← «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».
مهم: فكّ الضغط أولاً وارفع الملفات نفسها لا ملف zip. اقتراح اسم للمستودع: imla ← https://اسم-المستخدم.github.io/imla/

5) ارفع مجلد audio كما هو مع بقية الملفات: فيه أصوات الإملاء المسموع (تعمل دون صوت عربي في الجهاز). رخصة الأصوات في audio/LICENSE.txt.

6) استوديو التسجيل بصوتك: افتح https://اسم-المستخدم.github.io/اسم-المستودع/studio.html
   - سجّل الكلمات والجمل واحدة واحدة (تُحفظ في المتصفح، فيمكنك التوقف والعودة).
   - اضغط «صدّر مجلد الأصوات» فيُنزَّل audio.zip.
   - فكّه، وارفع محتوى مجلد audio (١٦ ملف mp3 وindex.json وLICENSE.txt) إلى مجلد audio في المستودع:
     افتح مجلد audio في GitHub ← Add file ← Upload files ← اختر الملفات ← Commit changes.
   - يسمع الطلاب صوتك بعد دقيقة أو دقيقتين، دون حاجة إلى تحديث أي ملف آخر.
   صفحة الاستوديو غير مرتبطة من التطبيق، فلا يراها الطلاب إلا إن أعطيتهم رابطها.

7) إضافة كلمات وجمل جديدة: في الاستوديو اختر «أضف كلمة أو جملة»:
   - كلمة فيها همزة: اكتبها مشكولة، فيحسب البرنامج رسمها وصورها الخاطئة وتعليلها، ويرفضها إن خالفت القاعدة ليُنبّهك.
   - كلمة أخرى (ألف لينة، تاء وهاء…): اكتبها ورسومها الخاطئة (أو اضغط «اقترح») وتعليلها.
   - جملة للإملاء المسموع: تُضاف إلى درس «الإملاء المسموع».
   اختر المستوى والدرس، وأضف جملاً تُستعمل فيها الكلمة إن شئت، ثم سجّل صوتها وصدّر وارفع مجلد audio كالمعتاد.
   تظهر الإضافات للطلاب في أسئلة الدرس واختبار المستوى. ويمكنك تعديلها أو حذفها من «ما أضفته».
